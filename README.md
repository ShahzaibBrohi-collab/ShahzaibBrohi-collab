> **Brohi Clipping** is a next-generation Android application that automatically transforms horizontal YouTube/Twitch live streams into viral 9:16 vertical Shorts & Reels with on-device AI moment detection, 3D kinetic subtitles, and synthetic voice commentary.

- ⚡ **100% Serverless & Private**: Runs on-device with embedded FFmpeg and Python yt-dlp.
- 🧊 **3D Kinetic Subtitles**: Advanced `.ass` subtitle generator with isometric depth & bounce animations.
- 🤖 **Gemini AI Core**: Intelligent moment scoring, narrative hooks, and audio ducking.

👉 **[Download the Latest Release (APK)](https://github.com/ShahzaibBrohi-collab/Brohi-clipping/releases/tag/v1.0.0)**
